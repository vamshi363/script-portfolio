# Creator Scriptwriter Portfolio

A showcase portfolio for high-retention YouTube scripts, viral short-form hooks, and video strategy frameworks.

## 📂 Included Pages & Assets

- **`index.html`** / **`portfolio_creator_scriptwriter_long_form_youtube_viral_short_form_scripts.html`**:
  - Interactive portfolio featuring the 8x8 Chess Strategy, Typewriter Machine showcase, script frameworks (PREP, Duh Test, Desire Hooks), retention case studies, and automated script brief generator.
- **`Script_Portfolio.html`**:
  - Minimalist retro typewriter-themed script portfolio for Creator Circle.
